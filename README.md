# Arena playtest

[Download the Windows game](https://github.com/Lumas1231/arena-playtest/releases/latest)

Extract the ZIP, double-click **Play.cmd**, enter your name, and join the shared castle arena. No Rust or SpacetimeDB installation is needed.

The server runs on Jackson's PC and is available while he is hosting. Run Play again after a disconnection. The launcher retrieves the latest host address automatically.

WASD move, Shift sprint, Ctrl lock, Alt switch target, mouse sets guard, left click light, right click heavy/parry, middle click guard break, Space dodge, E feint. V changes camera, F1 shows controls, F5 selects a skin.

This repository contains playtest downloads and the current server address only. It does not publish the development or research workspace. The build is unsigned and experimental. See the included terms, credits and licenses. This independent prototype is not affiliated with Ubisoft.
